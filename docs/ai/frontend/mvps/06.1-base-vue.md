# MVP 06.1 — Base Vue y cliente HTTP

## Resultado

`apps/frontend` contiene un proyecto Vue 3 con TypeScript, rutas públicas/protegidas, estructura de carpetas y cliente HTTP basado en cookies.

## Pasos

1. Crear el proyecto con Vite, Vue Router, Pinia y Vitest.
2. Añadir variables públicas de API y configuración local de desarrollo.
3. Crear el cliente HTTP con `credentials: 'include'` y normalización de errores.
4. Crear layout, ruta de acceso y una ruta protegida provisional.
5. Añadir estados de carga, vacío y error reutilizables.

## Criterios de aceptación

- `npm run dev`, pruebas, lint y build funcionan desde `apps/frontend`.
- Ningún secreto llega a variables de cliente.
- Un `401` puede ser interpretado de manera uniforme por el cliente HTTP.

## Pruebas

- Cliente HTTP: éxito, error JSON y error de red.
- Router: ruta pública y protección provisional.

## Estado

Completado el 2026-11-19. Validado con pruebas unitarias, lint, build, Docker Compose y respuesta HTTP de Vite en `localhost:5173`.
