# MVP 06.6 — Calidad y operación

## Resultado

El frontend cuenta con trazabilidad segura, pruebas E2E, accesibilidad y validaciones automáticas en CI.

## Pasos

1. Añadir captura de errores sin cookies, textos privados ni URLs firmadas.
2. Completar pruebas E2E de identidad y conversación entre dos usuarios.
3. Añadir comprobaciones de accesibilidad al flujo principal.
4. Configurar CI para pruebas, lint, tipos y build de API y frontend.

## Criterios de aceptación

- Un cambio con lint, test o build fallido no supera CI.
- Los artefactos de prueba no contienen secretos ni datos de sesión.
- El flujo principal es navegable por teclado.

## Pruebas

- Ejecución del pipeline en una rama de prueba.
- Auditoría de accesibilidad y E2E en entorno Docker.
