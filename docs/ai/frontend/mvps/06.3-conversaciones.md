# MVP 06.3 — Conversaciones y mensajes

## Resultado

Una sesión autenticada puede consultar conversaciones, abrir una y enviar/listar mensajes paginados.

## Pasos

1. [x] Crear store de conversaciones y servicios HTTP.
2. [x] Mostrar lista, estado vacío y error recuperable.
3. [x] Crear vista de mensajes y compositor accesible.
4. [x] Implementar cursores de paginación y carga de mensajes anteriores.

## Criterios de aceptación

- Enviar un mensaje lo muestra solo tras confirmación del API.
- El compositor conserva el texto ante errores de red.
- La paginación no duplica ni cambia el orden de mensajes.

## Pruebas

- Unitarias: store de cursor, deduplicación, orden cronológico, reintento y confirmación de envío; componentes de lista vacía, error al crear y borrador al fallar el envío.
- Manuales desde la interfaz:
  1. Ejecuta `docker compose --profile app up -d --build` y abre `http://localhost:5173`.
  2. Registra dos cuentas de prueba desde la interfaz (por ejemplo, Ada y Bob) y anota sus correos.
  3. Inicia sesión como Ada, crea una conversación con el correo de Bob y confirma que aparece el chat.
  4. Envía un mensaje y confirma que aparece con hora local. Si la API falla, el texto debe permanecer en el compositor.
  5. Abre una segunda sesión del navegador como Bob, entra al mismo chat y confirma que puede leer la conversación. Actualiza la página para sincronizar mensajes; tiempo real se añade en MVP 06.4.
  6. Envía más de 20 mensajes y pulsa **Cargar mensajes anteriores**. Comprueba que aparecen en orden y no duplicados.
  7. Comprueba una conversación inexistente y el estado vacío de una cuenta nueva; ambos deben ofrecer una acción recuperable.
