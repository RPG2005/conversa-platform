# MVP 06.5 — Adjuntos y preferencias

## Resultado

El usuario adjunta archivos permitidos y configura si recibe correo de notificación.

## Pasos

1. Implementar el flujo URL firmada → carga → validación → mensaje.
2. Mostrar progreso, errores y metadatos públicos del adjunto.
3. Solicitar URL de descarga bajo demanda.
4. Crear pantalla o sección de preferencias de correo.

## Criterios de aceptación

- No se muestra ni persiste una URL firmada después de usarse.
- Los errores de tipo o tamaño se explican antes o después de la carga.
- La preferencia se guarda y se recupera para el usuario autenticado.

## Pruebas

- Composable de adjuntos: éxito, tipo no permitido y error de red.
- E2E: PDF válido y cambio de preferencias.
