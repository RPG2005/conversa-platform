# MVP 06.5 — Adjuntos y preferencias

## Resultado

El usuario adjunta archivos permitidos y configura si recibe correo de notificación.

## Pasos

1. [x] Implementar el flujo URL firmada → carga → validación → mensaje.
2. [x] Mostrar progreso, errores y metadatos públicos del adjunto.
3. [x] Solicitar URL de descarga bajo demanda.
4. [x] Crear pantalla de preferencias de correo.

## Criterios de aceptación

- No se muestra ni persiste una URL firmada después de usarse.
- Los errores de tipo o tamaño se explican antes o después de la carga.
- La preferencia se guarda y se recupera para el usuario autenticado.

## Pruebas

- [x] Composable/servicio de adjuntos: éxito, tipo no permitido y error de red.
- [ ] Manual: subir un PDF permitido, completar y enviarlo en un mensaje.
- [ ] Manual: descargar el adjunto desde el mensaje recibido.
- [ ] Manual: verificar que un `.txt` y un archivo mayor de 10 MB se rechazan antes de subir.
- [ ] Manual: cambiar las preferencias de correo, recargar la vista y confirmar que el valor persiste.

## Prueba manual

1. Inicia sesión y abre una conversación existente.
2. Escribe texto, selecciona un PDF de menos de 10 MB y pulsa **Enviar mensaje**. Espera el estado de carga y confirma que el mensaje muestra nombre y tamaño.
3. En la otra cuenta, abre la conversación y descarga el PDF desde el mensaje.
4. Intenta seleccionar un `.txt` y un archivo superior a 10 MB; la interfaz debe explicar el rechazo y no debe iniciar la carga.
5. Desde **Preferencias**, desactiva los avisos por correo, guarda, recarga la página y comprueba que continúa desactivado. Después vuelve a activarlo.
