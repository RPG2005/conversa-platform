# Guía visual y accesibilidad

- Prioriza una columna de conversaciones y un panel de chat legibles en escritorio y móvil.
- Diferencia visualmente mensajes propios, remotos, fallidos y en envío sin depender solo del color.
- Coloca hora y estado de entrega en la esquina inferior de cada burbuja.
- Muestra siempre un control de reintento ante errores recuperables.
- El compositor debe conservar el texto ante un error de red.
- Los adjuntos muestran nombre, tipo y tamaño; la descarga es una acción explícita.
